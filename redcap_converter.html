Collapse Mode Quick Guide
wide: Creates naturally sorted columns (field__i1, field__i2, ..., field__i10).
auto: Keeps single-entry fields as one column and expands multi-line fields wide.
join: Combines all non-empty values in order into one cell.
unique: Combines distinct non-empty values into one cell.
first / last: Keeps earliest or latest non-empty value.
count / min / max / sum / mean: Numeric or count summaries per record.
